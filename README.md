### Hi there 👋

I'm Krishna, a Computer Science Ph.D. student at Louisiana State University
working on quantum software engineering: how quantum programs and the tools
behind them are built, where they break, and how to debug them. Outside of
papers, I build open-source tools for learning and experimenting with complex
technical topics like quantum computing and cryptography.

### Quantum computing

- **[QisDebug](https://github.com/kriss-u/QisDebug)**: Zero-touch debugger for Qiskit. One `start()` call records every gate, transpiler pass, and mid-execution statevector onto a timeline you can explore in a GUI, a terminal, or through an AI agent. [PyPI](https://pypi.org/project/qisdebug/)
- **[QisPlay](https://github.com/kriss-u/QisPlay)**: Browser environment for playing with Qiskit and Qiskit Aer. [Live](https://qisplay.nepcodex.com/)
- **[QisLearn](https://github.com/kriss-u/QisLearn)**: Interactive educational website for learning quantum computing with Qiskit, built on PyAST. [Live](https://qislearn.nepcodex.com/)

### Developer tools

- **[PyAST](https://github.com/kriss-u/py-ast)**: A TypeScript library that parses Python in the browser. [Playground](https://pyast.nepcodex.com/)
